多交易所 / 多品种商业化交易指挥中心

关键用户流程

从“看板”变成“下单前操作链”
1
选择交易所与市场

确定账户、币种、合约/现货、地域与时区。

2
挑选品种并加入工作区

把 BTC、ETH、XAU 等加入观察或执行清单。

3
配置 Agent 策略

参数、权限、触发条件、回退机制。

4
风险确认

仓位、杠杆、损失阈值、人工审批。

5
监控与复盘

执行、偏差、告警、绩效、审计。

组件规范

统一风格，减少“空态拼装感”
组件规范用途
全局选择器左对齐、两级层级、支持最近使用与收藏交易所 / 市场 / 品种
工作区卡片可拖拽、可分组、支持执行态徽标策略、观察、告警
风险条红黄绿三级，明确“阻断 / 需确认 / 可执行”下单前确认
空态给目标、给下一步动作、给示例数据首次上手 / 断连 / 无数据

逐页改版

围绕商业化交易闭环重构

Dashboard

从“运行时状态”升级为“今日交易态势”：市场、策略、风险、执行、告警五块并列，顶部固定全局选择器。

Orders

增加订单生命周期、撤改追踪、异常订单池、人工介入入口，默认展示工作区维度而非纯列表。

Risk

以“预执行检查 + 实时风控 + 事后复盘”三段式呈现，风险确认必须成为明确步骤。

Strategies

改成策略库 + 策略编辑器 + Agent 编排器，强调模板、版本、灰度与回滚。

Monitoring

突出交易链路、连接健康、延迟、错误率、告警队列与审计日志。

Settings

拆成连接、权限、通知、数据源、偏好五块，让首次上手有向导入口。

空态策略

每个空态都要推动下一步
不要只说“尚未接入”，而要给出“为什么空、下一步做什么、谁来做”。首次上手建议用向导式流程覆盖连接、选择器、工作区和首个策略。
