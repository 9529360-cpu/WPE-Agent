# 私人全自动部署验收合同

## 合同地位

本文定义 WPE 当前落地的权威验收边界。当前产品是供单一私人用户使用的商业级软件，不是当前销售或公开发行版本。凡历史路线、Epic、界面文案或流程描述与本文冲突，均以本文为准。

## 人的唯一动作

- 人只配置明确用于 Testnet/Sandbox 的交易 API 凭据，不承担其他运行中操作。
- 凭据由桌面宿主按既有安全边界写入和保管；文档、日志、审计、界面快照和测试产物不得包含密钥明文。
- 初始设置完成并启动自动运行后，不要求人执行 approve、reject、revoke、L2 审核或 L3 审核，也不以人工在线、人工确认或人工兜底作为闭环成立条件。

## 自动闭环

- Market Agent 自动取得市场事实并持续更新可用性与新鲜度状态。
- Research Agent 自动形成可追踪的研究事实、证据和不确定性标记。
- Strategy Agent 自动生成、筛选和管理策略信号，不得绕过确定性边界直接触发交易变更。
- Risk Agent 对每次执行意图实施确定性 Risk Gate；未明确放行不得执行。
- Execution Agent 仅在 Testnet/Sandbox、有效授权和 Risk Gate 放行后自动执行，并通过统一可靠执行路径完成交易变更。
- Recovery Agent 自动处理超时、未知订单、部分失败和状态不一致；无法确认安全状态时进入拒绝、隔离或暂停。
- Audit Agent 自动记录事实，不参与授权，不改变决定，也不创建等待人工处理的审批队列。
- 任一 Agent 的输出都不能绕过 Risk Gate、执行隔离、恢复规则或审计边界。

## 公开行情

- 公开行情由系统自动采集，用户无需为读取公开行情配置交易 API。
- 交易 API 仅用于账户私有数据以及交易的执行、查询和管理，不得作为公开行情采集的前置条件。
- 行情来源、时间戳、新鲜度、错误和降级状态必须可追踪；不得伪造、推断或用静态标签冒充实时事实。
- 行情不可用、陈旧、来源未知或能力不受支持时，依赖该行情的交易动作必须 fail closed。

## Testnet/Sandbox 凭据与自动 smoke

- 当前桌面 Binance API 的授权范围被明确限定为 Testnet 假钱环境，不得解释为 Mainnet 授权。
- 在没有真实 Mainnet API 和独立明确授权时，系统绝不得触发任何真实资金操作；Testnet 凭据或成功记录不得被推断为 Mainnet 能力。
- 系统已获得在该 Testnet 环境执行自动 smoke 的明确授权，不需要额外人工审批。
- smoke 必须验证官方 Testnet 端点、环境身份、凭据可用性和安全边界；任一项无法证明时不得发单。
- 本合同只定义授权与验收条件，不声明自动 smoke 已执行或已通过。

## Fail-Closed 验收

出现以下任一情况时，系统必须自动拒绝、隔离或暂停相关动作，并记录原因与状态变化：

- 无法证明当前环境是 Testnet/Sandbox，或检测到 Mainnet 端点、Mainnet 能力或环境混淆。
- 凭据缺失、失效、权限不符、来源不明或无法安全读取。
- 市场、账户、持仓、订单、风险或恢复状态为未知、陈旧、不一致或不受支持。
- Risk Gate 未明确放行，或执行路径无法证明经过统一可靠执行边界。
- 订单结果未知、恢复未完成、审计持久化失败，或安全约束无法被确定性验证。

Fail-closed 结果不得转换为人工审批请求。恢复运行只能由系统在安全条件重新得到确定性证明后自动进行；否则维持拒绝、隔离或暂停状态。

## 审计验收

- 审计只记录已发生的输入事实、Agent 决定、确定性规则结果、理由码、执行尝试、交易所响应、恢复动作、状态变化和最终结果。
- 审计不得被描述为审批、授权、背书或人工复核机制。
- 审计记录不得包含 API key、secret、token 或其他可复用凭据明文。

## 当前非目标

- 当前销售、公开发行、多人组织协作、客户运营或商业化包装。
- Mainnet 接入、Mainnet 交易或任何形式的真实资金授权。
- approve、reject、revoke、L2/L3 审核、人工 Review 队列或以人工确认作为自动闭环前置条件。
- 以人工审批替代 fail-closed，或在安全性无法证明时继续交易。
- 声称 Testnet 自动 smoke 已执行或已通过，除非另有可验证的实际运行证据。

## 最终验收判定

只有当初始设置后无需人工介入、公开行情可自动采集、全部 Agent 能在 Testnet/Sandbox 内形成可审计自动闭环，并且所有未知或不安全状态都自动 fail closed 时，才符合当前私人全自动落地目标。任何依赖人工审批、允许 Mainnet、要求公开行情交易 API，或把审计当作授权的实现均不验收。
