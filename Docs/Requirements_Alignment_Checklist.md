### 2. 策略模拟模块

#### 您的需求
```
功能：对每条策略进行模拟交易，考虑实际成本（手续费、滑点、杠杆利息等）
输出：每条策略在当前资金下的预期收益百分比
特性：支持多策略并行模拟、支持杠杆策略、可设收益阈值、支持模拟日志记录
```

#### 新架构实现

**接口**: `IStrategyEvaluationService`

```csharp
? EvaluateAsync()                 // 评估单个策略
? EvaluateMultipleAsync()         // 并行评估多个策略
```

**特性实现**:

```csharp
? 手续费计算: 0.05% (现货) / 0.02% (合约)
? 滑点估算: 0.1% per 交易
? 杠杆利息: 基于借贷率和持仓天数
? 输出: StrategyEvaluationResult 包含:
   - NetProfit: 净收益 (考虑所有成本)
   - ProfitRatio: 收益率 (% 相对账户)
   - SharpeRatio: 风险调整收益
   - RiskLevel: 风险等级 (Low/Medium/High)
   - TradeCount: 交易次数
```

**验证清单**:
- [ ] 能正确计算交易成本（手续费 + 滑点）
- [ ] 能正确计算杠杆利息
- [ ] 并行评估 10+ 个策略 < 5 秒
- [ ] 评估结果可记录和追踪
- [ ] 支持设置收益阈值过滤

**预期性能**:
- 单策略评估: < 500ms
- 10 个策略并行: < 3 秒

### 6. 循环控制模块

#### 您的需求
```
功能：控制整个闭环自动循环
流程：数据抓取 → 策略模拟 → 筛选 → 实盘 → 日志记录 → 循环下一轮
特性：支持固定时间间隔触发、支持连续运行和异常自恢复
```

#### 新架构实现

**核心**: `IAutomatedTradingEngine`

```csharp
? StartAsync()                    // 启动闭环循环
? StopAsync()                     // 停止循环
? GetStatus()                     // 获取运行状态
```

**闭环流程** (6 步):

```
步骤 1: 采集数据 ────────────→ IDataCollectionService
        ├─ 市场数据 (WebSocket)
        └─ 账户信息

步骤 2: 评估策略 ────────────→ IStrategyEvaluationService
        ├─ 并行回测所有策略
        └─ 计算收益率、Sharpe、风险

步骤 3: 筛选排序 ────────────→ IStrategyFilterService
        ├─ 按阈值筛选
        └─ 优先级排序

步骤 4: 实盘执行 ────────────→ IOrderExecutor
        ├─ 计算仓位 (IPositionManager)
        ├─ 检查杠杆 (ILeverageController)
        ├─ 执行订单
        └─ 异常重试 (IErrorRecoveryHandler)

步骤 5: 记录日志 ────────────→ ITradingRecorder
        ├─ 评估结果 → 数据库
        ├─ 执行记录 → 数据库
        └─ 周期统计 → 数据库

步骤 6: 等待循环 ────────────→ 延迟后回到步骤 1
        └─ 间隔时间可配置 (默认 5 分钟)
```

**循环控制配置**:

```csharp
AppSettings {
    CycleIntervalSeconds = "300"        // 5 分钟一个循环
    MaxConcurrentStrategies = "3"       // 最多同时执行 3 个策略
    MinProfitThreshold = "0.02"         // 最低收益率 2%
    TradingSymbols = "BTCUSDT,ETHUSDT"  // 交易对
}
```

**异常恢复**:

```csharp
? 数据采集异常: 重试 3 次，然后跳过这个周期
? 策略评估异常: 只评估成功的策略，继续执行
? 实盘执行异常: 自动重试，最多 3 次
? 记录异常: 只记录成功的，继续下个周期
? 灾难性异常: 等待 30 秒后重新开始
```

**验证清单**:
- [ ] 引擎能启动
- [ ] 能进入循环并执行所有 6 个步骤
- [ ] 循环间隔可配置
- [ ] 能正确停止
- [ ] 异常能自动恢复
- [ ] 长时间运行 (24h+) 稳定
- [ ] 状态能正确反映

**预期性能**:
- 单周期执行时间: 10-30 秒 (取决于策略数)
- 循环误差: < 1 秒
- 内存泄漏: 24h 运行后 < 10MB 增长
- CPU 使用率: < 20% (平均)
