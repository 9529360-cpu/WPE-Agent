# 分阶段落地计划

## Phase 0: 设计冻结
- 定义插件类型、manifest、权限字典、签名格式。
- 统一 provider / skill / strategy / risk 的平台术语。

## Phase 1: 平台内核
- 做插件注册表、安装器、版本比较、回滚器。
- 接入现有 provider catalog 和 skill registry。

## Phase 2: 安全壳
- 加入签名验证、沙箱、权限拦截、审计日志。
- 先支持只读类插件和通知类插件。

## Phase 3: 交易类扩展
- 上线交易所适配器、数据源、策略、风险规则。
- 仅测试网灰度。

## Phase 4: 商业化
- 市场页、付费墙、订阅/按量计费、企业授权。
- 开发者控制台与结算报表。

## Phase 5: 生态化
- 插件评分、兼容矩阵、推荐位、合作伙伴计划。
