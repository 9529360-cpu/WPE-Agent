# 权限与安全模型

## 权限分级
- `read`: 只读市场、账户、配置、日志。
- `trade`: 下单、改单、撤单。
- `risk`: 读取或建议风险参数。
- `notify`: 发送通知。
- `brain`: 调用外部/本地 LLM。
- `admin`: 安装、升级、回滚、卸载。

## 高危权限
- `withdraw`
- `private-key`
- `mainnet-trade`
- `filesystem-write`
- `network-arbitrary`
- `code-exec`

## 沙箱
- 插件默认进受限进程或受限宿主域。
- 仅允许声明式网络白名单。
- 文件系统只读，除插件专属数据目录外不可写。
- 交易类插件不能直接持有主密钥，只能拿短期令牌。

## 签名与审核
- 每个包必须带发布者签名。
- 平台保存信任根与吊销列表。
- 审核分三层：静态扫描、行为模拟、人工审批。
- 上架后持续复审版本差异。

## 运行时控制
- 插件调用必须打点：调用者、权限、耗时、结果、错误。
- 超时、限流、熔断、降级均由平台强制执行。
- 违规权限立即禁用并回滚到上个稳定版本。
